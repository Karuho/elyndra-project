# Elyndra 0.7.32-alpha

This release hardens supervised general-knowledge acquisition after real local-model output omitted the approved subject. Plan-approved kind, subject and locale are now immutable, while model discrepancies remain auditable.

It also adds bounded multisource evidence packages with independent SHA-256 provenance, sequential cross-review by multiple local auditors, domain/project-aware retrieval and explicit CLI state guidance.

Security properties remain unchanged: no silent learning, automatic promotion, destructive knowledge deletion, background execution, remote retrieval, model downloads, tool transfer or policy authority for tutors and auditors.

Technical state:

- visible version `0.7.32-alpha`;
- wheel version `0.7.32a0`;
- SQLite schema 40;
- 102 registered skills;
- no JavaScript or TypeScript changes;
- Node is not required for this release.
