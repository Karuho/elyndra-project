# Elyndra 0.7.31-alpha

This release hardens reviewed general knowledge acquisition and adds non-destructive governance.

## Highlights

- controlled confidence normalization for numeric values, percentages and Spanish/English qualitative labels;
- the original confidence value and mapping remain reviewable;
- failed acquisition plans can only be retried as new plans with new approvals;
- exact duplicates are blocked and parallel same-subject knowledge requires an explicit reason;
- potential conflicts are persisted and resolved without deleting knowledge;
- source observation and revalidation dates preserve history while withholding due knowledge from operational answers;
- SQLite schema 39;
- 102 skills;
- no JavaScript or TypeScript changes and no Node requirement;
- `CHANGELOG.md` remains unchanged;
- 560 tests across 65 test files passed in the implementation workspace.

Tutors and auditors remain advisory language models without tools, permissions, memory authority, policy authority or automatic promotion rights.
