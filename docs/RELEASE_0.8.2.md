# Elyndra 0.8.2-alpha

## Personal coaching, wellbeing and interface parity

This release restores CLI/web equivalence as an explicit project invariant and
adds the second personal-assistant domain on top of the cognitive executive.

- visible version `0.8.2-alpha`;
- wheel version `0.8.2a0`;
- SQLite schema 43;
- skills remain 102;
- web chat and CLI share `ElyndraApplication.ask`;
- real HTTP tests cover organizer, knowledge and runtime metadata;
- the web page and responses expose the exact runtime version;
- a Personal workspace provides organizer and wellbeing views and confirmed writes;
- local wellbeing check-ins are bounded and deterministic;
- coaching plans and actions require explicit owner operations;
- no diagnosis, treatment authority, notification daemon or background intervention;
- CHANGELOG, README, SECURITY and CONTRIBUTING are synchronized;
- JavaScript changed, so Node syntax validation is mandatory.
